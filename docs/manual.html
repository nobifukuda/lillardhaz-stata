1. Overview

lillardhaz fits a two-equation simultaneous model of the kind introduced by Lillard (1993): a pair of processes, each either a binary probit outcome or a continuous-time hazard duration, linked through a single correlation parameter rho between their underlying error terms and estimated jointly by maximum likelihood via a Gaussian copula.

Four families of model are supported, selected by eq1() and eq2():

eq1()eq2()Typical use
probitlognormala binary decision correlated with a log-normal AFT duration (e.g. Waite & Lillard 1991)
lognormallognormaltwo correlated log-normal AFT durations
probitpgompertza binary decision correlated with a flexible piecewise-Gompertz duration
pgompertzpgompertztwo correlated piecewise-Gompertz durations

Every combination can also be fit with nocorr, which restricts rho=0 and — as shown in Section 5 — reduces algebraically to two independent univariate fits, giving a natural nested baseline for a likelihood-ratio test of correlation.

2. The model

Each equation has a location index built from covariates, theta = Xb. For a probit equation, Y=1 iff theta + u > 0 with u ~ N(0,1); the latent index theta is itself standard-normal-scaled and so is already a copula residual. For a hazard equation, timing follows either:

  • log-normal: log(T) = theta + sigma·e, e ~ N(0,1) — the standard accelerated failure-time form; or
  • piecewise Gompertz: log h(t) piecewise linear in t (Section 3).

For any hazard equation, define the copula residual via the probability integral transform:

z = Phi-1( 1 - S(t) )

which is exactly standard normal under the fitted model, by construction, regardless of which timing distribution generated S(t). This is what lets a log-normal equation be paired with a piecewise-Gompertz equation under the same copula machinery.

3. Piecewise Gompertz timing

The piecewise Gompertz hazard (Lillard 1993, following his footnote 6) makes the log-hazard a continuous, piecewise-linear function of time. Given K-1 interior nodes 0 < n1 < ... < nK-1 (set by nodes1()/nodes2(), defining K segments) and per-segment slopes s1,...,sK:

log h(t) = theta + Lk + sk·(t - nk-1)   for t in segment k

where Lk is built recursively (L1=0, Lk+1 = Lk + sk·(nk-nk-1)) so the log-hazard has no jumps at the nodes. Because each segment's hazard is exp(linear), the cumulative hazard has a closed form on each segment (integrate exp(a+bx) analytically, with a linear-in-t fallback when a segment's slope is numerically zero), so S(t) = exp(-H(t)) and f(t) = h(t)S(t) require no numerical integration at any stage. This is implemented once, for a general number of segments, in _lillardhaz_pgomp.ado and shared by both equations.

nodes1()/nodes2() are literal duration time values you choose, not a segment count. Each entry is the actual time point where the hazard's slope is allowed to change — there is no auto-spacing, equal-interval, or quantile-based placement. K is simply derived from how many values you list (listing 3 nodes gives 4 segments; 1 node gives 2). For example, to place breakpoints at t=2, t=6, and t=15 (4 segments): 
. lillardhaz time1 event1 time2 event2, eq1(pgompertz) eq2(pgompertz) ///
    x1(x1) x2(x2) nodes1(2 6 15) nodes2(4)

4. The joint likelihood, case by case

Write a = sqrt(1-rho2). When both equations are hazards, with residuals (z1,z2) and marginal density/survival (f1,S1,f2,S2):

both observed

phi2(z1,z2;rho) / (phi(z1)phi(z2)) · f1·f2

1 observed, 2 censored

f1 · ( 1 - Phi((z2-rho·z1)/a) )

1 censored, 2 observed

f2 · ( 1 - Phi((z1-rho·z2)/a) )

both censored

Phi2(-z1,-z2;rho)

When equation 1 is a probit (outcome y1, index theta1) and equation 2 is a hazard (residual z2, density/survival f2/S2):

y1=1, obs 2 observed

f2 · Phi((theta1+rho·z2)/a)

y1=1, obs 2 censored

Phi(theta1) - Phi2(theta1,z2;-rho)

y1=0, obs 2 observed

f2 · Phi(-(theta1+rho·z2)/a)

y1=0, obs 2 censored

Phi2(-theta1,-z2;-rho)

Phi2(·,·;rho) is the bivariate normal CDF (Stata's binormal()). The censored-cell formulas follow the inclusion-exclusion identity P(Z1>z1,Z2>z2) = 1-Phi(z1)-Phi(z2)+Phi2(z1,z2;rho) = Phi2(-z1,-z2;rho).

5. Independence and the nocorr reduction

Setting rho=0 gives a=1, and every formula above factors exactly into the product of the two marginal terms — e.g. the both-observed hazard×hazard cell becomes phi(z1)phi(z2)·f1·f2/(phi(z1)phi(z2)) = f1·f2, and the both-censored cell becomes Phi(-z1)Phi(-z2) = S1·S2. This is exactly Lillard's own identification result: with no correlation, the joint likelihood is the product of two independent univariate likelihoods. lillardhaz's nocorr option fits this restricted model using the same evaluator (with rho fixed at 0 and no atanh_rho equation) rather than a separate program, and Section 7 confirms empirically that it reproduces Stata's own univariate streg fits to 5+ significant figures.

6. A correction relative to the original templates

The widely-circulated ml templates this package supersedes generally build the joint bivariate density by inverting (1-rho2) into the wrong term of the exponent, or by mixing marginal density where a marginal hazard was intended (the same class of error documented for the univariate case in the companion splitpopsurv-stata package). This package derives each of the eight branches in Section 4 directly from the bivariate normal density/CDF and the definition of the copula residual, and verifies every branch by simulation (Section 7) rather than by inspection alone.

7. Verification

Every eq1()×eq2() combination, correlated and independent, was verified by simulating data under known parameters and confirming lillardhaz recovers them. Representative results (n=20,000–25,000 per run):

eq1() / eq2()corrtrue rhoestimated rhonotes
lognormal / lognormalyes0.5000.491all regression coefficients within 2% of truth
probit / lognormalyes-0.400-0.418
pgompertz / pgompertzyes0.3500.3612 nodes each side, all slopes recovered
probit / pgompertzyes0.3000.302the second segment's slope was weakly identified under heavy censoring in this particular design — a data/power property, not a code defect
lognormal / lognormalno (nocorr)0 (fixed)—coefficients matched two separate streg fits to 5+ significant figures
An earlier version of the shared d0 evaluator had a depvar-indexing bug: it always read equation 2's duration from Stata's second dependent variable slot, which is only correct when equation 1 is a probit (a 3-depvar layout). With a hazard equation 1 (a 4-depvar layout), that slot instead holds equation 1's own failure indicator. The bug was caught precisely because the pgompertz×pgompertz verification run above failed to evaluate at the true parameter values (Log likelihood = -<inf>) even from an exact ml init, which is what should be numerically impossible if the likelihood is coded correctly. Fixed by routing equation 2's duration through a small conditional ($ML_y2 when equation 1 is a probit, $ML_y3 otherwise) set once near the top of the evaluator.

9. Examples

* Probit & log-normal hazard, correlated
. lillardhaz y1 time2 event2, eq1(probit) eq2(lognormal) x1(x1) x2(x2)

* Piecewise Gompertz & piecewise Gompertz, correlated, 2 nodes each
. lillardhaz time1 event1 time2 event2, eq1(pgompertz) eq2(pgompertz) ///
    x1(x1) x2(x2) nodes1(5) nodes2(4)

* Same, but independent (nested test of rho=0)
. lillardhaz time1 event1 time2 event2, eq1(pgompertz) eq2(pgompertz) ///
    x1(x1) x2(x2) nodes1(5) nodes2(4) nocorr

* Predictions
. predict S2_hat
. predict f2_hat, dens2
. predict xb1_hat, xb1
